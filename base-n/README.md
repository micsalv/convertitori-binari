# Base N ↔ Decimale

Conversione generica tra una base N (2, 4, 8, 16, 32) e il sistema decimale.

## Funzionalità

- Scelta della base di lavoro
- Conversione in entrambe le direzioni
- Visualizzazione dei passaggi

## Prerequisiti

È consigliata la familiarità con il sistema binario e con il metodo posizionale.
