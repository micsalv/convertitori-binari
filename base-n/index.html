Regola generale di conversione:
Per convertire un numero da base 10 a una base N qualsiasi si applica il metodo delle divisioni successive: si divide per N, si annota il resto (sempre compreso tra 0 e N-1) e si ripete con il quoziente fino ad ottenere 0. Il risultato si legge dai resti, dall'ultimo calcolato al primo. Per la conversione inversa, da base N a base 10, si applica il calcolo posizionale: ogni cifra si moltiplica per il peso Nposizione e si sommano i contributi.

Procedura del Metodo delle Divisioni Successive per Base N

  1. Si divide il numero decimale dato per la base N.
  2. Si annota il quoziente intero e il resto (sempre compreso tra 0 e N - 1).
  3. Si continua a dividere il quoziente ottenuto per N finché non si raggiunge un quoziente pari a 0.
  4. Il numero nella base N è dato dalla sequenza dei resti letti dall'ultimo calcolato (cifra più significativa) fino al primo.
  5. Se la base supera 10, i resti dal valore 10 al 15 si scrivono con le lettere A, B, C, D, E, F.

Procedura del Calcolo Posizionale (da Base N a Base 10)

  1. Si scrive il peso di ciascuna posizione: N0 per la cifra più a destra, N1, N2 e così via procedendo verso sinistra.
  2. Si converte ogni cifra letterale nel suo valore (A = 10, B = 11, …, F = 15).
  3. Si moltiplica ogni cifra per il proprio peso e si sommano tutti i contributi.

Esercizio di verifica guidato

Convertire il numero decimale 25510 in base 16 ed eseguire la riprova posizionale:

255 ÷ 16 = 15 (resto 15 = F)
 15 ÷ 16 =  0 (resto 15 = F)

Risultato: FF16

Riprova: 15 · 16 + 15 = 25510
