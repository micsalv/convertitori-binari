# Binario ↔ Decimale

Convertitore interattivo per la conversione tra sistema binario e sistema decimale.

## Funzionalità

- Binario → Decimale: metodo posizionale con visualizzazione dei pesi
- Decimale → Binario: divisioni successive con tabella dei resti
- Interattivo: slider, pulsanti dei bit, campo numerico

## Uso didattico

Adatto per l'introduzione ai sistemi di numerazione posizionali.
