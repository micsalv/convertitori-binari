# Binario ↔ Base 2 elevato a n

Conversione tra binario e basi potenza di 2 (4, 8, 16, 32) tramite raggruppamento dei bit.

## Funzionalità

- Inserimento di stringhe binarie fino a 32 bit
- Raggruppamento automatico in base alla base scelta
- Visualizzazione dei gruppi con eventuale padding a sinistra
- Conversione inversa: ogni cifra viene espansa nel suo gruppo di bit

## Metodo didattico

Il raggruppamento dei bit è il metodo più rapido per passare tra base 2 e basi che sono potenze di 2.
