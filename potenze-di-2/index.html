# Cifra Valore decimale Gruppo di bit (padding a sinistra)

Report Sintetico & Quadro Teorico

Il metodo dei raggruppamenti dei bit per le basi potenza di 2.

Regola generale:
Poiché ogni base 2n è una potenza di 2, ogni cifra di quella base corrisponde esattamente a n bit. Basta raggruppare i bit partendo da destra in blocchi di n bit e tradurre ciascun blocco nella cifra corrispondente. Se il numero di bit non è multiplo di n, si aggiungono zeri a sinistra.

Procedura — Binario → Base 2n

  1. Si determina n: numero di bit per cifra (n=4 per l'esadecimale).
  2. Si aggiungono zeri a sinistra finché il numero di bit è multiplo di n.
  3. Si raggruppano i bit in blocchi di n, partendo da destra.
  4. Ogni blocco, letto come numero posizionale, fornisce una cifra della base di arrivo.

Procedura — Base 2n → Binario

  1. Ogni cifra della base di partenza viene convertita nel suo valore decimale.
  2. Ogni valore viene scritto in binario su esattamente n bit (padding a sinistra).
  3. Si concatenano i gruppi: il risultato è il numero binario.

Esercizio di verifica guidato

Convertire 101101112 in esadecimale e in ottale, poi verificare la riprova.

Esadecimale (n=4):
  1011 0111
   B    7   → B7₁₆

Ottale (n=3):
  padding: 010 110 111
  2   6   7   → 267₈

Verifica: 18310

B716 = 11·16 + 7 = 183

2678 = 2·64 + 6·8 + 7 = 183
